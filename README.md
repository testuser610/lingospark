# LingoSpark Python Starter

A functional learning-app prototype made with Python and Streamlit.

## Run
Install Python 3.10+, then run:
`pip install -r requirements.txt`
`streamlit run lingospark.py`

## Android phone note
This `.py` file is not an APK and Android does not normally run Streamlit apps directly. You can upload the files to a cloud development/hosting service that supports Streamlit, then open its app link in your phone browser.

## Included
- Home dashboard, XP, coins, streak display and daily goal
- English learning lessons with Malayalam translations
- Quiz, challenge demo and mistake review
- Achievement badge hall
- Following/friends demo and activity
- League leaderboard demo
- Rewards shop and mystery chests
- Profile and settings

## Important limitations
Progress is stored in the current Streamlit session and may reset. Friends and leaderboard entries are sample data, not real users. Speaking/listening are text-based practice demos. Real accounts, database sync, real audio/speech recognition, notifications, privacy/security, moderation and app-store packaging must be added before public release.
